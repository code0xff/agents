# Agent Economy Observatory

Backend-less dashboard for the AI agent economy: marketplaces, ERC-8004 registrations, x402 payments.
All data is read in the browser from public RPCs and public APIs. No server, no API keys.

Live: https://code0xff.github.io/agents/

- Marketplace and registry directory with activity metrics
- ERC-8004 registration log streamed from Base, Ethereum and BNB
- x402 payment flow graph built from USDC EIP-3009 settlements on Base
- Light/dark themes, four locales (en, ko, ja, zh)

See `AGENTS.md` for project rules and the documentation index.

```
npm install
npm run dev
```
